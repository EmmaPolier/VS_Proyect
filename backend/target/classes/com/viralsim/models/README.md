# Models

Contiene las clases de modelo que representan las estructuras de datos fundamentales del sistema.

## Clases principales

- `Nodo.java` - Representa un nodo/usuario en la red
- `Arista.java` - Representa una conexión/amistad entre nodos
- `Grafo.java` - Representa la red completa
- `Estado.java` - Enumeración de estados posibles de un nodo
