# Database

Contiene la capa de acceso a datos (DAOs) para persistencia en MySQL.

## Clases principales

- `ConexionBD.java` - Gestiona la conexión a la base de datos
- `NodoDAO.java` - CRUD para nodos
- `AristaDAO.java` - CRUD para aristas
- `SimulacionDAO.java` - CRUD para simulaciones
- `HistorialDAO.java` - Almacena historial paso a paso
- `MetricaDAO.java` - Almacena métricas calculadas
