# Propagation

Contiene las implementaciones de los tres modelos de propagación de información.

## Modelos disponibles

- `ModeloPropagacion.java` - Interfaz base para todos los modelos
- `ModeloViral.java` - Modelo Viral: cada nodo contagia con su probabilidad
- `ModeloCascadaIndependiente.java` - Cascada Independiente: propagación basada en aristas
- `ModeloUmbralLineal.java` - Modelo de Umbral: contagio por presión social
